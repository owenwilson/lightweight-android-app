# lightweight android app

- let's create lightweight android-app
- version gradle `8.7`

## setup project

- let's download and build dependencies

```sh
gradle wrapper --gradle-version 8.7 
```

- compile and install

```sh
gradle clean
gradle installDebug
```

- additional example
```sh
gradle installDebug --continous
gradle installDebug -t
```
